# 🖥️ Suyog OS

### A developer portfolio disguised as an operating system.

**Suyog OS** is an interactive, terminal-inspired developer portfolio built to showcase my profile, technical skills, projects, engineering interests, and development journey through an OS-like interface.

Instead of the traditional portfolio layout, Suyog OS brings a command-line experience to the browser — combining a minimal terminal aesthetic, system-style dashboards, and interactive navigation.

## ✨ Features

- **Terminal Interface** — Navigate the portfolio using interactive terminal commands.
- **Neofetch Profile** — A system-style overview of my developer profile, environment, and technical interests.
- **About** — Learn about my background, experience, and engineering interests.
- **Skills** — Explore my technical stack and tools.
- **Projects** — Discover projects I've built and the engineering behind them.
- **Architecture** — Explore system designs and technical architecture.
- **System Monitor** — A dashboard-style view of system and portfolio metrics.
- **GitHub Integration** — Visualize contribution activity and GitHub statistics.
- **LeetCode Integration** — Display problem-solving statistics, contest ratings, and achievements.
- **Timeline** — Explore my development journey and milestones.
- **Resume & Contact** — Access my résumé and connect with me.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/suyog-os.git
```

Navigate to the project directory:

```bash
cd suyog-os
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.
